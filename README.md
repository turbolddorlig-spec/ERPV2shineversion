# zahialga• ERP V2

Захиалга, агуулах, хүргэлт, тооцооны систем. Одоогоор **Модуль 0 (Суурь)** бэлэн: нэвтрэх, хэрэглэгч, эрх, үйлдлийн түүх, дизайны бүтэц.

## Cloud.mn сервер дээр суулгах (анх нэг удаа)

Шинэ сервер дээр Docker суусан байх шаардлагатай. Дараа нь:

```bash
git clone https://github.com/turbolddorlig-spec/ERPV2shineversion.git erp-v2
```

```bash
cd erp-v2 && ./install.sh
```

Скрипт 4 зүйл асууна: домэйн (байхгүй бол хоосон), Супер админы утас, нэр, нууц үг. Үлдсэнийг өөрөө хийнэ:
нууц тохиргоо үүсгэх → бүтээх → database бэлдэх → Супер админ үүсгэх → анхны backup. HTTPS сертификатыг автоматаар авна.

## Шинэчлэх (шинэ хувилбар гарах бүрт)

```bash
cd erp-v2 && ./update.sh
```

Шинэчлэхийн өмнө backup авна, migration-ийг автоматаар ажиллуулна, ажиллаж байгааг шалгана. Алдаа гарвал өмнөх хувилбар руу буцах командыг харуулна.

## Backup

- Өдөр бүр 03:00 цагт `backups/` хавтсанд автоматаар, 14 хоног хадгална.
- `update.sh` бүрийн өмнө нэмэлт backup.
