Алдаа удирдлага ба Миний торгууль

2026.11.11 · Хуучин ERP-ийн «Алдаа удирдлага» (/salary-accounting), «Алдаа бүртгэл» (/my-penalties), асуудлаас автомат торгууль үүсгэдэг логикийг уншсан дүн, таны хариулт. Таныг «Модуль 7а-ын төлөвлөгөөг зөвшөөрч байна» гэж бичихээс өмнө код бичихгүй.

1. Хуучин ERP-ийн алдаа (давтахгүй)

  • Торгууль нэмэх, жагсаалт харах API нэвтрэлтгүй — хэн ч торгууль тавьж, бүх ажилтны торгуулийг харах боломжтой байсан; «хэн тавьсан»-ыг хөтөч илгээдэг. → V2: эрхтэй, хэн гэдгийг серверээс.
  • Нягтлан «Цалингаас хасах» дарж чаддаггүй (эрхийн шалгалтад роль буруу бичигдсэн). → засна.
  • Буруу торгуулийг бүрмөсөн устгадаг — ул мөргүй. → шалтгаантай «Цуцлах», түүхэнд үлдэнэ.
  • Автомат торгуулийг хүнийг нэрээр нь хайж олдог (олдохгүй бол торгууль үүсдэггүй, эсвэл санамсаргүй агуулахын ажилтанд). → V2: захиалга авсан ажилтан, падаан бэлдсэн ажилтныг дугаараар нь (id).
  • Огнооны шүүлт UTC-ээр (өглөө 8 цагаас өмнөх торгууль өмнөх өдөрт). → Улаанбаатарын цагаар.

2. Хуудсууд (хуучин бүх боломж)

  1. Алдаа удирдлага (/penalties) — Супер админ, Админ, Ахлах оператор, Нягтлан, Торгуулийн ажилтан.
    • Картууд: Нийт торгууль, төрөл бүрээр (Опп / Хүргэлт / Маркетинг / Агуулахын алдаа) тоо ба дүн, хасагдаагүй дүн.
    • Шүүлт: огноо (эхлэх–дуусах), төрөл, ажилтан, төлөв (Хасагдаагүй / Цалингаас хассан / Цуцлагдсан); хуудаслалттай жагсаалт.
    • «Торгууль нэмэх»: ажилтан сонгох (ролоор нь төрөл автоматаар), алдааны нэр — Опп: Коммент шүүгээгүй, Чат шүүгээгүй, Дугаар үлдээсэн, Шэйр хийгээгүй, 3 удаа залгаагүй, Бусад; Жолооч: Шэйр хийгээгүй, Хоцролт (минут), Бусад; Маркетинг, Агуулах: Бусад; пэйж, үйлчлүүлэгчийн утас/нэр, захиалгын дугаар; дүн (анхдагч нь тохиргооноос).
    • Мөр бүр: «Цалингаас хассан» тэмдэглэх (Нягтлан, Админ), шалтгаантай «Цуцлах».
    • «Ажилчдын мэдээлэл» таб: ажилтан сонгоход тэр хүний торгууль (нийт/хасагдаагүй) ба буцаагаагүй барааны зээл (Модуль 2-оос) нэг дор.
  2. Миний торгууль (/my-penalties) — бүх ажилтан: зөвхөн өөрийнх; нийт, хасагдсан, хасагдаагүй дүн; огноогоор; жагсаалт (алдаа, захиалга, хэн тавьсан).
  3. Тохиргоо → «Торгуулийн дүн» (Супер админ, Админ): автомат торгуулийн дүн (анх 5,000₮) — төрөл бүрээр; «Торгууль нэмэх»-ийн анхдагч дүн.

4. Цалингаас хасах (таны хариулт)

  • Одоо нягтлан «Цалингаас хассан» гэж тэмдэглэнэ (хуучин шиг, хэн, хэзээ).
  • Дараагийн «Ажилтны цалин» хуудас цалин бодоход хасагдаагүй торгуулийг автоматаар суутгаж, «Цалингаас хассан» болгоно — торгуулийн хуудас ба цалин хоёуланд нь «хасагдсан» гэж давхар харагдана; нэг торгууль хоёр удаа хасагдахгүй.
  • Хасагдсан торгуулийг цуцлахгүй (эхлээд цалингийн тооцоонд засна).

5. Таны шийдвэр (#90)

  1. Автомат торгууль яг хуучнаар (Опп / Маркетинг / Агуулахын алдаа), Жолоочийн алдаа торгуульгүй.
  2. Торгуулийн дүнг Тохиргоо хэсэгт гараар засна.
  3. Буруу торгуулийг шалтгаантай «Цуцлах» (устгахгүй).
  4. Цалин бодоход хасагдсан гэж давхар харагдана.

6. Тест

Эрх (хэн юу харах/тавих), автомат торгууль 3 төрөл ба давхардахгүй, цуцлах, хасах, миний торгууль зөвхөн өөрийнх, огноо Улаанбаатарын цагаар, урт текст (B3), 150 хэрэглэгчийн ачаалал, Docker шинэчлэл. Үлдэгдэлд хүрэхгүй.

Танаас: зөвшөөрвөл «Модуль 7а-ын төлөвлөгөөг зөвшөөрч байна» гэж бичнэ үү. Өөр алдааны нэр (жишээ: «Хоцролт» оператор, маркетингт) нэмэх бол хэлээрэй.
