1. Юу хийсэн (хуучин ERP-ийн бүх боломж)

  1. Нягтлан (/accounting) «Нягтлан бодох бүртгэл»: өдөр (‹ ›, календарь, сүүлийн өдрүүд, Өчигдөр, Өнөөдөр, Маргааш), шүүлт (жолооч, төлөв, орон нутаг); товч OKEY, Гүйцэтгэл солих, Цалингийн дүрэм (Супер админ), Төлбөр тооцооны бүртгэл, Падаан.
    • Картууд: Нийт захиалга, Хүргэсэн, Цуцласан (маргааш, тооцохгүй), Орон нутаг, Жолооч цалин, Хүлээн авах дүн; «Тооцооны задаргаа», «Тооцоо нийлсэн» (Бэлэн/Данс/Өр, урьдчилгаа, нэмэлт бараа, нийлсэн/хүсэлт/огт явуулаагүй); «Өнөөдөр өр тавьсан / төлсөн».
    • «Жолооч бүрийн хураангуй»: гүйцэтгэл ✏️ Засах («Гараар засагдсан 80% → 95.5%»), нэг захиалгын хөлс ба аль дүрмээр, дүн, цалин, хүлээн авах, «Тооцоо хийсэн» тэмдэг, «Тооцоо нийлсэн» (Бэлэн/Данс/Өр + «Тооцоо нийлэх»), урьдчилгаа / нэмэлт барааны «Зөвшөөрөх», OKEY/ХОРИГ тэмдэг, НИЙТ ДҮНГЭЭР.
    • Жолооч дээр дарахад: үзүүлэлт, «✅ ПАДААН ТААРСАН», хэсэгчилсэн хүргэлт, «⚠️ Нэмэлт бараа — тооцоонд орохгүй», нээлттэй өр; «Тооцооны задаргаа», «Гүйцэтгэлийн тооцоо» (дүрэм, одоогийн мөр тодорсон), «Төлбөрийн мэдээлэл»; падааны захиалга бүр (тэмдэг, болиулсан бараа, шалтгаан) + «Төлөв солих».
  2. Жолоочийн апп — «Орлого» таб: өдөр, ижил самбар, «Авах дүн», «Тооцоо нийлэх» (Бэлэн + Данс + Өр, Данс урьдчилж бөглөгдөнө), «Тооцоо буцаах», «Нэмэлт барааны тооцоо», «Урьдчилгаа шилжүүлэх». «Төлбөр тооцоо» таб: компанид өгөх өр (зөвхөн харах).
  3. Төлбөр тооцооны бүртгэл: жолооч бүрийн өр, «Өр нэмэх» (төрөл, тайлбар, дүн, захиалга), «Өр хасах» (шалтгаантай), «Дутуу бараа одоо бодох».
  4. Гүйцэтгэл солих (Супер админ): Энгийн / Тусгай / Орон нутаг (хөлс 1,000–10,000₮) — өнөөдрөөс хүчинтэй, түүх хадгална.
  5. Цалингийн дүрэм (шинэ, Супер админ): хөлс (5000/4500/4000), орон нутгийн анхны хөлс, 35-ын босго, 3 төрлийн хувийн босго — «хэдэн өдрөөс»; өнгөрсөн өдөр өөрчлөгдөхгүй; «Хуучин ERP-ийн утга» товч.
  6. Банкны импорт (/bank-import), хуучнаар нь: CSV, Gmail sync (+ автомат), 7 статистик, табууд (Таарсан / Таараагүй / Хэсэгчлэн / Илүү / Давхардсан / Буцаасан / Дүн өөрчлөгдсөн), хайлт, огноо, «Гараар тааруулах», «Буцаасан», CSV экспорт. 3. Хуучин ERP-ийн алдаа засагдсан

  • Огноо зөрдөг байсан (нягтлан үүссэн өдрөөр, жолооч хуваарилсан өдрөөр, тооцоо «өмнөх өдөр») → нэг падааны өдөр.
  • Цалингийн томъёо 6 газар → нэг функц (calc.ts); жолооч ба нягтлангийн тоо ачааллын тестэд ч яг ижил.
  • Тушаах дүнг утас илгээдэг, «Тооцоо хийсэн» нэвтрэлтгүй → сервер тооцно, бүх товч эрхтэй (тест: оператор / жолооч 403).
  • Өнгөрсөн өдөр чимээгүй өөрчлөгддөг → баталгаажсан өдөр түгжигдэнэ: хүргэлт буцаах, төлөв солих, гүйцэтгэл засах, падаан буцаах бүгд 409; тооцооны хуулбар хадгалагдана.
  • Банк: зарлагыг орлого гэж тоолдог → алгасна; хэн ч бүгдийг устгах → байхгүй; хуучин захиалгыг цуцалж шинэ дугаар → дугаар хэвээр «Мөнгө орсон».
  • Баталгаажуулах үед давхар дарвал 2 өр → өгөгдлийн сангийн хамгаалалт, нэг л удаа (зэрэг дарахад шалгасан).

4. Үлдэгдэл (B2) ба дутуу барааны өр

  • Нягтлангийн «Төлөв солих» жолоочийн нэрийн өмнөөс журналаар: хүргэсэн → бараа жолоочоос үйлчлүүлэгчид; буцаах → үйлчлүүлэгчээс жолоочид. Агуулахад шууд хүрэхгүй; бараа агуулахад буцсан бол «Хүргэсэн болгох» боломжгүй (давхар хасалтгүй).
  • Дутуу бараа (#82 6): өдөр бүр 00:00-ийн дараа жолоочийн гарт байгаа буцаах бараа (хүргэлтэд яваа захиалгынхаас гадна) → бараа тус бүрт нэг өр, системийн үнээр. Агуулахад буцаах, нэмэлт бараагаар зарах, дахин хүргэхэд тоо нь буурч, 0 болоход автоматаар хаагдана. Барааны журнал огт хөдлөхгүй (тестээр шалгасан).
  • Бүх тестийн төгсгөлд тулгалт 0, сөрөг үлдэгдэл 0.

Нэмэлт: зөвхөн ажлын байрнаас нэвтрэх (#86, таны хүсэлт)

  • Тохиргоо → «Зөвхөн ажлын байрнаас нэвтрэх»: асаах чагт, хэнд хамаарах ролиудыг чагтлан сонгоно (жишээ нь Оператор, Маркетинг), ажлын интернэтийн IP-г ажил дээрээ байхдаа «Одоогийн IP-г нэмэх» товчоор нэмнэ (хэд хэдэн IP болно).
  • Сонгосон ролтой ажилтан ажлын IP-аас гадуур бол нэвтрэхгүй. Ажил дээрээ нэвтэрч гэртээ очвол хуудас нээгдэхгүй («Та зөвхөн ажлын байрнаас нэвтэрнэ»). Хүсэлт бүрт шалгана.
  • Ажлын сүлжээнд холбогдсон бол утсаар ч нэвтэрнэ. Тохируулаагүй (IP-гүй эсвэл унтраалттай) бол хаанаас ч нэвтэрнэ.
  • Хамгаалалт: Супер админыг хэзээ ч хязгаарлахгүй; ажлын IP-гүйгээр асаахгүй; өөрийгөө түгжих тохиргоог хадгалахгүй; гаднаас нэвтрэх оролдлого түүхэнд бичигдэнэ; хуурамч IP (X-Forwarded-For) илгээж тойрох боломжгүй (Docker дээр шалгасан). Олон ролтой бол хязгааргүй ролтой нь бол чөлөөтэй.
  • Тест: 411/411, E2E 1020/0 (гаднаас API/хуудас/нэвтрэлт хаагдах, бусад роль хэвийн, оператор тохиргоо солихгүй).

Танд мэдэх зүйл

  • Тооцоо илгээх: падааны бүх захиалга дууссаны дараа л (хүргэсэн / цуцалсан / маргааш). Хуучинд зөвхөн анхааруулдаг байсан — дуусаагүй захиалга дараа нь өөрчлөгдвөл баталгаажсан тоо зөрөх тул хориглосон.
