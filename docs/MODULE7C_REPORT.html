Нийлүүлэгч (гадны дэлгүүр)

2026.11.11 · Батлагдсан төлөвлөгөө (#96–#98) — хуучин логикийг хуулж, танд хохиролтой алдааг зассан. Таны баталгааг хүлээж байна.

Бүх тест амжилттай: 423/423 unit+integration, E2E 1039/0, 150 зэрэг хэрэглэгч алдаа 0 (p95 19мс), урт текст хальсан 0, Docker шинэчлэл амжилттай. Барааны үлдэгдэлд огт хүрээгүй.

1. Юу хийсэн

  1. Нийлүүлэгч (/supplier) — Супер админ, Админ: самбар (идэвхтэй дэлгүүр, энэ сарын / өнөөдрийн борлуулалт, нийт төлөх үлдэгдэл), Өнөөдөр / Өчигдөр / Уржигдарын захиалга, дэлгүүрийн жагсаалт (үлдэгдэл, шилжүүлээгүй өдөр).
  2. Дэлгүүр: нэр, холбогдох хүн, утас; засах; идэвхгүй болгоход нийлүүлэгч нэвтрэхгүй болно.
  3. Өдрийн тооцоо — падааны өдрөөр: бараа бүрээр хүргэсэн (үйлчлүүлэгчийн авсан) тоо, цуцалсан тоо, борлуулалт, Опп / Хүргэлт / Маркетинг / Бусад суутгал (1 ширхэгийн суутгал × авсан тоо), цэвэр дүн. Падааны бүх захиалга дуусаагүй бол шилжүүлэхгүй (анхааруулна).
  4. «Шилжүүлсэн гэж тэмдэглэх» — өдөр түгжигдэж, тэр үеийн тооцоо хадгалагдана (дараа тохиргоо өөрчилсөн ч өөрчлөгдөхгүй).
  5. Буцаалт автоматаар: шилжүүлсний дараа захиалга цуцлагдвал / үйлчлүүлэгч аваагүй бол зөвхөн нийлүүлэгчийн барааны дүнгээр (борлуулалт − суутгал) дараагийн шилжүүлгээс хасагдана; шалтгаан (захиалга, бараа, тоо, огноо, тооцоо) танд ч, нийлүүлэгчид ч харагдана. Хожим хүргэгдсэн бол «Нэмэгдэл». Хасалт хүрэхгүй бол үлдэгдэл нь дараагийн шилжүүлэгт шилжинэ.
  6. Нэгтгэл (огнооны хүрээ: борлуулалт, суутгал, цэвэр, суутгалын хувь, шилжүүлсэн / шилжүүлээгүй) ба Шилжүүлсэн түүх.
  7. Бараа: хайж оноох (эхлэх өдөртэй), хасах, бараа бүрийн 1 ширхэгийн суутгалын тохиргоо.
  8. Суутгалыг гараар засах — зөвхөн Супер админ (#98): тухайн өдөр, тухайн бараанд, шалтгаантай; хуучин/шинэ дүн түүхэнд.
  9. Нэвтрэх эрх: нийлүүлэгчид утас + түр нууц үг (анх нэвтрэхдээ солино), нууц үг сэргээх. Нийлүүлэгч зөвхөн өөрийн тооцоо, нэгтгэл, буцаалтыг харна, юу ч өөрчлөхгүй.

2. Танд хохиролтой хуучин алдаа — засагдсан

  • Нэг барааг 2 дэлгүүрт оноож болдог (давхар төлөх) → нэг бараа зөвхөн нэг нийлүүлэгчид (өгөгдлийн сангийн хамгаалалттай, тестээр).
  • Нийлүүлэгчийн барааны хөнгөлөлтийг та төлдөг → хямдарсан бараа өөрөө хүлээнэ (#97).
  • Хэсэгчилсэн хүргэлтэд захиалсан бүх тоог төлдөг → зөвхөн үйлчлүүлэгчийн авсан тоо.
  • Буцаалт захиалгын нийт дүнгээр (таны бараа + хүргэлт), гараар хайдаг → автомат, зөвхөн нийлүүлэгчийн барааны цэвэр дүнгээр.
  • Шилжүүлсэн өдрийн дүн дахин хадгалахад өөрчлөгддөг → түгжинэ.
  • Тооцоог хөтөч бодоод илгээдэг → сервер бодно.
  • Нийлүүлэгчийн нууц үг ил текстээр, хуудас бүгдэд ижил нууц үгээр → энгийн нэвтрэлт, нууц үг зөвхөн hash.
  • Өдөр UTC-ээр (өглөө 8-аас өмнөх захиалга өмнөх өдөрт) → Улаанбаатарын цагаар, падааны өдрөөр.
  • Барааг кодоор холбодог, хассан даруйд түүх алга болдог → дугаараар, хугацаатай. Бүх үйлдэл түүхэнд.

3. Хэрэгжүүлэлтийн жижиг шийдвэр (#99)

  • Жолоочийн нэмэлт борлуулалт (падаангүй зарсан нийлүүлэгчийн бараа) мөн тэр өдрийн тооцоонд орно — нийлүүлэгчийн бараа зарагдсан бол мөнгө нь түүнд очно.
  • Барааг хасахад өнөөдрийн падаан хуучин дэлгүүрт тооцогдоно, маргаашаас хамаарахгүй (шинэ дэлгүүрт маргаашаас оноогдоно).
  • «Шилжүүлснийг буцаах» — зөвхөн Супер админ, зөвхөн хамгийн сүүлд шилжүүлсэн өдөр (андуурсан үед).
  • Буцаалтыг сүүлийн 90 хоногийн шилжүүлсэн өдрүүдэд автоматаар шалгана (хуудас нээх, шилжүүлэх бүрт).
  • Хуудасны «Өнөөдөр / Өчигдөр / Уржигдар» захиалгын тоо хуучин шиг авсан огноогоор; дүн нь зөвхөн нийлүүлэгчийн барааны үнээр (хуучинд захиалгын нийт дүн байсан).
  • Эрхийн хүснэгт: Нийлүүлэгч хуудсыг Админ ч удирдана (хуучин шиг, төлөвлөгөөнд батлагдсан).
