# ERP V2 — DESIGN REQUIREMENTS (APPROVED)

> Эзэн 2026-11-10-нд баталсан. Энэ бол ERP V2-ийн батлагдсан дизайны шаардлага.
> **Prototype гаргах болон кодонд хэрэгжүүлэх зөвшөөрлийг тус тусад нь авна.**

## 1. Үндсэн дизайн: Premium Hybrid
- Зөөлөн gradient background
- Цэвэрхэн, цайвар үндсэн хэсэг
- Орчин үеийн sidebar
- Premium card design
- Зөөлөн shadow, rounded corners
- Цэгцтэй typography

## 2. Өнгөний горим: Dark / Light
- Хоёр горимыг хоёуланг нь дэмжинэ.
- Хэрэглэгч горимоо өөрөө сонгоно.
- Сонгосон горим хадгалагдана.

## 3. Дэлгэцийн нягтрал: Balanced
- Хэт том зайтай ч биш, хэт шахуу ч биш.
- Хүснэгтэд олон мөрийг ойлгомжтой харуулна.
- Компьютер, таблет, гар утсанд responsive байна.

## 4. Нэгдсэн Design System
Бүх модуль дараах нэг ижил бүрэлдэхүүнийг ашиглана:
Sidebar, Header, Button, Input, Table, Modal, Dropdown, KPI cards, Status badges.

## 5. Хурд ба хялбар байдал нь дизайнаас чухал
- Хэт их animation хэрэглэхгүй.
- Хүснэгт болон захиалгын ажиллагааг хүндрүүлэхгүй.
