# ERP V2 — DATABASE БА DATA MIGRATION FINAL DECISION

> Эзэн 2026-11-10-нд эцэслэн баталсан. `MASTER_RULES.md` доторх database болон migration-тэй холбоотой өмнөх ерөнхий тайлбаруудаас **давуу хүчинтэй**. Шийдвэр #2-ыг орлоно.

## 1. Хөгжүүлэлтийн бүх хугацаанд
- ERP V2 нь тусдаа, хоосон database-тай байна.
- Хуучин ERP-ийн production database-тай холбогдохгүй.
- Хөгжүүлэлтийн явцад хуучин бодит өгөгдлийг татаж авахгүй.
- Бүх модуль, функц, тестийг хуурамч (dummy/test) өгөгдлөөр гүйцэтгэнэ.
- Бодит системийн ажиллагааг дуурайсан тестийн захиалга, бараа, жолооч, агуулах, санхүүгийн өгөгдөл үүсгэнэ.
- 150 зэрэг хэрэглэгч, 1,000,000+ захиалгын ачааллыг тестийн өгөгдлөөр шалгана.

## 2. Хөгжүүлэлт дуусах хүртэл
Хуучин системийн бодит өгөгдлийг татах, импортлох, production database-тай холбох үйлдэл хийхгүй.

## 3. Эцсийн шилжилтийн үе шат
ERP V2-ийн бүх модуль бүрэн дуусаж, тестүүд амжилттай болж, эзэн системийг бүхэлд нь баталсны дараа л:
1. Cloud.mn дээр ажиллаж буй хуучин ERP-ийн database-ээс бодит өгөгдлийг татна.
2. Backup файл үүсгэнэ.
3. Өгөгдлийг V2-д тохирсон форматаар бэлтгэнэ.
4. V2-ийн тусдаа database руу import хийнэ.
5. 5,000+ барааны код, нэр, зураг болон холбоосыг тулгана.
6. Захиалга, агуулахын үлдэгдэл, жолоочийн тооцоо, санхүүгийн мэдээллийг тулгана.
7. Импортын дараа бүх өгөгдлийн бүрэн бүтэн байдлыг шалгана.
8. Бүх зүйл зөв болсны дараа production шилжилтийг тусдаа зөвшөөрлөөр хийнэ.

## 4. Хатуу хориг
Эцсийн шилжилтийн зөвшөөрөл хүртэл хуучин production database-д холбогдохгүй, бодит өгөгдөл татахгүй, импорт хийхгүй.
Хуучин ERP хэвийн ажилласаар байна.

## 5. Нэмэлт (2026-11-10, шийдвэр #21)
- V2 нь хөгжүүлэлтийн явцад Cloud.mn дээр **тусдаа database, тусдаа хаягаар** ажиллана. Эзэн болон ажилтнууд өөрсдөө зохиосон өгөгдлөөр (бодит захиалга авч байгаа мэт) жинхэнэ ашиглалтаар туршина.
- Энэ туршилтын өгөгдөл нь §1-ийн "хуурамч тестийн өгөгдөл" гэж тооцогдоно.
- Эцсийн шилжилтэд **зөвхөн V2-ийн** database-ийг reset хийж хоосолно (эзний тусгай зөвшөөрлөөр), дараа нь хуучин өгөгдлийг §3-ын дагуу оруулна.
- Хуучин ERP-ийн database, сервер, кодыг хөндөхгүй хэвээр.
