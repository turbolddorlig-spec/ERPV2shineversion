# Нөөц хуулбар (backup) ба сэргээх — эзэнд зориулсан заавар

## Автоматаар юу хийгддэг вэ
- **Өдөр бүр 03:00** database-ийн бүрэн хуулбар авна (захиалга, мөнгө, үлдэгдэл, хэрэглэгч — бүгд).
- Хуулбар бүрийг **шалгана**: эвдэрсэн, дутуу, хэт жижиг бол хадгалахгүй, Супер админд ⛔ анхааруулга гарна.
- Сервер дээр: сүүлийн **14 өдөр** + **12 сар** (сар бүрийн эхний хуулбар). Барааны зураг: сервер дээр.
- **Google Drive** (холбосны дараа): сүүлийн **7 өдөр**, **4 долоо хоног**, **12 сар** — «zahialga-backup» хавтаст.
  Нэг хуулбар ~130 MB (1 сая захиалга) → нийт ~3 GB. 80% дүүрвэл анхааруулга, 90% бол хамгийн хуучин сарынх автоматаар устна.
- `./update.sh` шинэчлэх бүрийн өмнө хуулбар авна; авч чадаагүй бол **шинэчлэхгүй**.
- Супер админд анхааруулга: 26+ цаг хуулбар авагдаагүй, хуулбар амжилтгүй, Drive холбогдоогүй / алдаа / дүүрсэн.

## Google Drive холбох (нэг удаа)
1. Зөвхөн хуулбарт зориулсан **шинэ Google бүртгэл** нээнэ (жишээ `zahialga.backup@gmail.com`).
2. Компьютерээсээ серверт ингэж холбогдоно:
   ```bash
   ssh -L 53682:127.0.0.1:53682 root@СЕРВЕРИЙН-IP
   ```
3. Серверт:
   ```bash
   cd ERPV2shineversion && ./setup-drive-backup.sh
   ```
4. «1» сонгоод гарах `http://127.0.0.1:53682/...` холбоосыг браузерт нээж, хуулбарын Google бүртгэлээр нэвтэрч **Allow** дарна.
5. Скрипт өөрөө шалгаж, нэг хуулбар Drive руу хуулна. Drive-даа «zahialga-backup» хавтас гарч ирнэ.

## Сэргээх (зөвхөн яаралтай үед)
```bash
./restore.sh
```
- Сервер дээрх хуулбаруудаас дугаараар сонгоно (`./restore.sh --drive` — Drive-аас татаж сонгоно).
- «СЭРГЭЭХ» гэж бичиж баталгаажуулна.
- Аюулгүй: эхлээд одоогийн өгөгдлийн хуулбар авна → шинэ database-д сэргээж шалгана → зөвхөн амжилттай бол солино.
  Хуучин database `erp_old_<огноо>` нэрээр үлдэнэ (буцаах боломжтой).
- 1 сая захиалгатай өгөгдөл ~1.5 минутад сэргэнэ (туршсан).
