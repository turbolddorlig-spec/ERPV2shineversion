Алдаа удирдлага ба Миний торгууль

2026.11.11 · Батлагдсан төлөвлөгөө (#90) + таны нэмэлт «алдааны нэрийг өөрөө үүсгэдэг» (#91). Таны «Модуль 7а-ыг баталж байна» гэсэн үгийг хүлээж байна.

Бүх тест амжилттай: 413/413 unit+integration, E2E 1026/0, 150 зэрэг хэрэглэгч алдаа 0 (p95 14мс), урт текст хальсан 0, Docker шинэчлэл амжилттай. Үлдэгдэлд хүрээгүй.

1. Юу хийсэн

  1. Алдаа удирдлага (/penalties): дээр нийт торгууль (хасагдаагүй / цалингаас хассан / цуцлагдсан), төрөл бүрийн 4 карт (дарахад шүүнэ); огноо, ажилтан, төлөвөөр шүүх; цэвэр жагсаалт (өнгөт цэг = төрөл, «автомат» тэмдэг); «Цалингаас хасах» (Нягтлан, Админ), шалтгаантай «Цуцлах».
  2. «+ Торгууль нэмэх» 4 алхамтай: ажилтан хайж сонгох → төрөл (ролоос автоматаар) → алдааны нэр (товчоор, анхдагч дүнтэй) → дүн; «Хоцролт»-д минут; нэмэлт: захиалга, пэйж, үйлчлүүлэгч, тайлбар.
  3. Алдааны нэрийг өөрөө үүсгэнэ (таны хүсэлт): «+ Шинэ алдааны нэр» — бичээд шууд торгууль тавина, жагсаалтад хадгална. «Алдааны нэрс» цонхонд төрөл бүрээр нэмэх, нэр/анхдагч дүн засах, нуух/сэргээх. Хуучин ERP-ийн нэрс анх бэлэн.
  4. «Ажилчдын мэдээлэл»: ажилтан сонгоход торгууль (нийт / хасагдаагүй / хассан) ба буцаагаагүй барааны зээл нэг дор.
  5. Миний торгууль (/my-penalties): бүх ажилтан зөвхөн өөрийнхөө — Энэ сар / Бүгд, төлөв, нийт · хасагдаагүй · хассан.
  6. Автомат торгууль (яг хуучин шиг): «Опп-руу явуулах» асуудлыг «Цуцлах»-д Опп-н алдаа → захиалга авсан ажилтан, Маркетингийн алдаа → захиалга авсан маркетинг ажилтан, Агуулахын алдаа → падааныг бэлдсэн ажилтан; Жолоочийн алдаа → торгуульгүй. Нэг захиалгад нэг төрөл нэг л удаа. Хариуцагч олдохгүй бол анхааруулна (гараар тавина).
  7. Тохиргоо → «Торгуулийн дүн (автомат)»: 3 төрлийн дүн (анх 5,000₮).

2. Хуучин ERP-ийн алдаа засагдсан

  • Торгууль тавих, харах API нэвтрэлтгүй байсан → эрхтэй (оператор 403 — тестээр).
  • Нягтлан «Цалингаас хасах» дарж чаддаггүй байсан → чадна.
  • Устгадаг байсан → шалтгаантай цуцлалт, түүхэнд үлдэнэ; цалингаас хасагдсаныг цуцлахгүй.
  • Автомат торгуулийг нэрээр хайдаг (буруу хүнд очдог) → дугаараар (id); падаан бэлдсэн ажилтныг одооноос хадгална.
  • Огнооны шүүлт UTC → Улаанбаатарын цагаар.

3. Танд мэдэх зүйл

  • Маркетингийн алдаа: V2-д энгийн маркетинг ажилтан захиалга авдаггүй тул автомат торгууль ихэвчлэн «хариуцагч олдсонгүй» гэж анхааруулна — Алдаа удирдлагаас гараар тавина. Хэрэв бараа бүр хариуцсан маркетинг ажилтантай байх бол «Барааны гарц» (Модуль 7)-д холбож болно.
  • Цалин: дараагийн «Ажилтны цалин» хуудас хасагдаагүй торгуулийг автоматаар суутгаж «Цалингаас хассан» болгоно — энд ч, цалинд ч давхар харагдана.
  • Өмнө нь бэлдсэн падаанд бэлдсэн ажилтны дугаар байхгүй — нэрээр нь (ганц таарвал) олно.
