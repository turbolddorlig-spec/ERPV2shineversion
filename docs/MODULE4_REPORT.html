1. Юу хийсэн (хуучин ERP-ийн урсгалаар, #66)

  • «Ахлах жолооч» — KPI (Хуваарилаагүй, Өнөөдөр/Маргааш оноосон, Хүргэлтэд, Өнөөдөр хүргэсэн), шүүлтүүр (хайлт, хуваарилалт, хүргэх огноо, үүссэн өдөр −2…+2, дүүрэг, «Орон нутаг», төлөв, жолооч, мөрийн тоо 20–500), Хайх / Цэвэрлэх, «Дүүргээр бүлэглэх», олноор хуваарилах мөр (жолооч + «Огноо солих»), мөр бүрт жолооч сонгох (ачаалал 20+ улаан, 10+ шар), огноо, «Жолоочдын захиалга» баруун самбар. Он сар өдөртэй, төлбөр хүлээж буй захиалгыг хуваарилахгүй.
  • «Жолоочид бараа өгөх» (iPad) — жолооч сонгох (OKEY/ХОРИГ, 🚚 захиалгын тоо, Бэлдээгүй / Бэлдэж байна / Бэлдсэн / Өгсөн), огноо; «Захиалга сонгох (бүгд)» → Падаан үүсгэх; бараа нэгтгэсэн Check хүснэгт (тавиурын кодоор эрэмбэлэгдсэн, зураг томруулах), явц «x/y (%)», «Бараа хайх», «Шалгаагүй»; Падаан буцаах · Бэлтгэсэн · Буцаах · Барааг бүрэн өгсөн; хэвлэх; түүх.
  • Нягтлан OKEY / ХОРИГ (#65) — өдөр бүр, шалтгаантай ХОРИГ; «Итгэлтэй» жолооч автоматаар OKEY. OKEY-гүй жолоочид падаан үүсэхгүй.
  • Check заавал (#65) — бүх барааг чагтлахгүй бол «Барааг бүрэн өгсөн» идэвхгүй.
  • Падаан өгсний дараа хуваарилсан захиалга → маргаашийн хүргэлт (#65); өгөхөөс өмнө бол падаанд автоматаар «ШИНЭ» тэмдэгтэй нэмэгдэнэ — хуучин шиг алга болохгүй.
  • Захиалгын хуудас — «Жолооч» багана бөглөгдөж, «Нэмэлт шүүлтүүр»-т «Жолооч» идэвхжсэн. Падаанд орсон захиалгыг засахгүй (хуучин шиг).
  • Падаан хэвлэх — огноо, жолооч, нийт захиалга, нийт дүн, барааны нэгтгэл (тавиур, Check), захиалга бүрийн бараа (үйлчлүүлэгчийн утас/хаяггүй), улаан санамж, «Агуулах баталгаажуулсан / Жолооч хүлээн авсан».

2. Хуучин ERP-ийн үлдэгдлийн алдаа яагаад гарахгүй вэ

  • Хуучин: бараа жолоочид өгөхөд агуулахаас хасагддаггүй, буцаалтад нэмэгддэг → давхар нэмэгдэж үлдэгдэл хөөрдөг байсан.
  • Шинэ: «Барааг бүрэн өгсөн» дарахад бараа үндсэн агуулахаас жолоочийн гарт нэг журналаар шилжинэ (HANDOVER), захиалгын нөөц суллагдана. Бараа хаана байна — тэнд л тоологдоно (дүрэм B2). Буцаалт (Модуль 5) жолоочоос агуулах руу — давхар нэмэгдэх боломжгүй.
  • Үндсэн агуулахад хүрэлцэхгүй бол юу ч өөрчлөгдөхгүй (сөрөг үлдэгдэлгүй), падаан дээр шараар «Дүүргэлтээр татна уу».
  • Нэг жолоочид нэг өдөрт нэг падаан, нэг захиалга нэг л идэвхтэй падаанд — database хамгаална. Зэрэг дарахад нэг л удаа.
